# Ripe

A systems programming language.

## Installation

### Debian

```
sudo apt install opam
```

## Usage

```
dune build                            # Compile
dune exec ripec -- <file.rp>          # Run on a file
dune exec ripec -- examples/hello.rp  # Example
```
